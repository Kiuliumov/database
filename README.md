# Database

A simple database management system implemented in C# as a course project for **Synthesis and Analysis of Algorithms** at the **Technical University of Sofia**.

The project explores how a database works internally by implementing its core components from scratch. Its planned functionality includes creating and managing tables, storing records on disk, processing SQL-like commands, filtering and sorting data, and building indexes for faster searches. Data structures and text-processing routines are implemented manually in accordance with the course requirements.

The solution is organized into separate projects for the command-line interface, query parsing, core database logic, storage, indexing, and shared types.
